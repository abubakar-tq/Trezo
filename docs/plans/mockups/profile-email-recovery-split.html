How the split untangles the monolith:
SetupShown only when the module isn't installed. A 3-step wizard (passkey/intro → trusted contacts → approvals & timing) in plain language. "Threshold" → "how many must approve"; "delay in minutes" → named safety-delay choices. One decision per screen.
ManageShown once installed. A calm status view: on-state summary, contact list with accepted/pending + resend, one "Approvals & timing" settings row, and turn-off. No setup steppers, raw weights, or the hidden SHOW_ADVANCED_RECOVERY_UI dead cards.
SafetyPure UI/structure split — the on-chain install/guardian/timing logic is unchanged, just reorganized by state. Plain-language labels wrap the same params (threshold, delay, weights).
